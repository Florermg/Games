# Quickstart: validar la opción Listening

1. `npm test`: todo en verde (pruebas nuevas en `English/tests/listening.test.mjs`).
2. `npm run versions` y luego `npm test` sin problemas de versiones.
3. Abrir `English/QuizA.html` (doble clic o `http://127.0.0.1:8765/QuizA.html`), elegir 5.º y un tema y presionar **🎧 Listening → 🎲 Generate**:
   - Etapa 1: ▶ Play; cada oración aparece como subtítulo con "n / N".
   - Next ▶ → etapa 2: suena el mismo audio y no hay texto.
   - Next ▶ → quiz de 5–6 preguntas con barra de audio; calificar y Finish → resultados.
4. 🖨 Print → Student sheet sin el texto; Answer key con "Read aloud" y las respuestas marcadas.
5. Probar los 18 temas en 5.º en vivo: ≥ 90% generan una actividad (SC-001).
6. Huella de GAMES-1 `f1 b9 82 7e 2c 76`.
7. Celular (390 px): los subtítulos sin scroll horizontal.
